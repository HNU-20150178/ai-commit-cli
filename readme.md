# ai-commit-cli (aic)

> Git staged 차이점(`git diff`)을 분석하여 AI 기반 Conventional Commits 메세지를 자동 생성해주는 CLI 도구

# Node.js 실행기를 사용함
# execa
 
## 사용법
### 1. 사전 조건
- Node.js v18 이상
- Git 설치 및 레포지토리 초기화 완료 git remote add origin https://github.com/HNU-20150178/ai-commit-cli.git

### 2. 프로젝트 설치 및 의존성 다운로드
```bash
# 패키지 설치
npm install

# 로컬 단축키 등록
npm link
```

### 3. 사용방법

# 터미널에서 실행
aic
